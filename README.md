# Portfólio

Site pessoal de Erick Castro, publicado em https://srkcire.github.io

O site inteiro está em um único arquivo, `index.html`, feito com HTML, CSS e JavaScript puros, sem build nem dependências. Os projetos exibidos ficam na lista `PROJECTS`, dentro do `<script>` no fim do arquivo: para adicionar ou editar um projeto, basta alterar essa lista.
