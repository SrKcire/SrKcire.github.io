# Portfólio

Site pessoal de Erick Castro, publicado em https://srkcire.github.io

O site inteiro está em um único arquivo, `index.html`, feito com HTML, CSS e JavaScript puros, sem build nem dependências. Os projetos exibidos ficam na lista `PROJECTS`, dentro do `<script>` no fim do arquivo: para adicionar ou editar um projeto, basta alterar essa lista. Cada projeto tem os destaques principais em `highlights`, recursos extras (que aparecem em "Ver mais") em `more` e a data da última atualização em `updated` (AAAA-MM-DD).
